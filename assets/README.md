# automation.ai Marketing Assets

This folder contains lead generation and nurturing materials for the automation.ai funnel.

## Files

- `automation-opportunity-checklist.md` — Clean Markdown version of the lead magnet (easy to print or convert to PDF)
- `automation-opportunity-checklist.html` — Nicely formatted HTML version (can be hosted or used as a landing page)
- `nurture-email-sequence.md` — 5-email nurture sequence to send after someone downloads the checklist
- `linkedin-post-templates.md` — 5 ready-to-use LinkedIn post templates designed to drive traffic to the checklist and site

## How to Use

1. Host or distribute the checklist (HTML or converted PDF)
2. Set up an email automation tool (or manual process) to send the nurture sequence when someone downloads
3. Post the LinkedIn templates regularly (1–2 per week)
4. Update links in the posts and emails to point to your site or direct email

## Goal

These assets support the overall marketing funnel aimed at generating qualified discovery calls that convert into bundle sales, implementation projects, and retainers.

For full strategy, see the main marketing-plan.md in the parent directory.
